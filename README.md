# Debye-Huckel Analyzer v.1.0.0

**Программа для моделирования и визуализации средних ионных коэффициентов активности электролитов по трём приближениям теории Дебая–Хюккеля.**


## О программе

**Наименование:** Debye-Huckel Analyzer v.1.0.0  
**Назначение:** Научный расчёт и визуализация коэффициентов активности электролитов в рамках классической теории Дебая–Хюккеля.  
**Область применения:** Физическая химия, электрохимия, учебный процесс.  
**Язык программирования:** Python.  
**Объём исходного кода:** 543 строки (с комментариями).  
**Тип:** Программа для ЭВМ с графическим интерфейсом пользователя (GUI).

Программа позволяет в интерактивном режиме исследовать поведение теоретических кривых зависимости $lg(\gamma^{±})$ от $\sqrt{I}$, накладывать на них экспериментальные данные и экспортировать результаты в распространённые форматы (PNG, CSV, PDF).

## Теоретическая основа

Теория Дебая–Хюккеля (1923 г.) — фундаментальная теория физической химии растворов электролитов, описывающая термодинамические свойства ионов в растворе через понятие **ионной атмосферы**.

Главный управляющий параметр — **ионная сила раствора** $ I $:

$$
I = \frac{1}{2} \sum_i c_i z_i^2
$$

где $ c_i $ — молярная концентрация иона, $ z_i $ — его заряд.

Программа реализует три последовательных приближения теории:

- **Первое (1-е) приближение теории Дебая-Хюккеля:**
    - Предельный закон
    - Формула: $ \lg \gamma_{\pm} = -A \lvert z_+ z_- \rvert \cdot \sqrt{I} $
    - Особенности применения: предел = точечные ионы (a = 0); работает при ионной силе I < 0.001

- **Второе (2-е) приближение теории Дебая-Хюккеля:**
    - Расширенный закон
    - Формула: $ \lg \gamma_{\pm} = -\frac{A \lvert z_+ z_- \rvert \sqrt{I}}{1 + B a \sqrt{I}} $
    - Особенности применения: учитывается конечный размер ионов (a — эффективный диаметр, Å); работает в диапазоне I ∈ [0.001; 0.1]
    
- **Третье (3-е) приближение теории Дебая-Хюккеля:**
    - С линейным членом
    - Формула: $ \lg \gamma_{\pm} = -\frac{A \lvert z_+ z_- \rvert \sqrt{I}}{1 + B a \sqrt{I}} + CI $
    - Особенности применения: полуэмпирическая поправка на гидратацию и ионную ассоциацию; работает до $ I \approx 0.5 $

**Константы для воды при 25°C:**
- A = 0.509 $\frac{л^{\frac{1}{2}}}{моль^{\frac{1}{2}}}$
- B = 0.329 $\frac{л^{\frac{1}{2}}}{моль^{\frac{1}{2}}}$

## Функциональные возможности

1.  **Автоматический расчёт ионной силы** из стехиометрии электролита.
2.  **Одновременный расчёт и визуализация** трёх приближений на едином графике.
3.  **Интерактивный выбор** активного приближения с маркировкой точки на кривой.
4.  **Загрузка экспериментальных данных** из CSV-файла и их наложение на теоретические кривые.
5.  **Экспорт результатов:**
    - График в **PNG** (300 dpi, готов к публикации).
    - Таблица данных в **CSV** (для дальнейшего анализа в Excel, OriginPro, Python).
    - Полный отчёт в **PDF** (с параметрами, результатами и графиком).
6.  **Пользовательские настройки** констант растворителя A и B (через меню).
7.  **Задел для расширения:** предусмотрен интерфейс для модуля автоматической подгонки параметров.

## Инструкция пользователя

### Основное окно

Интерфейс разделён на две панели:

- **Левая панель** — управление и результаты.
- **Правая панель** — интерактивный график.

### Пошаговый сценарий работы

1.  **Введите параметры электролита:**
    - Заряд катиона `z+` (например, `2` для Ca²⁺).
    - Заряд аниона `z-` (например, `-1` для Cl⁻).
    - Молярную концентрацию `c` в моль/л (например, `0.1`).

2.  **Выберите приближение** с помощью радиокнопок.
    - *Первое:* поля `a` и `C` заблокированы.
    - *Второе:* активно только поле `a` (эффективный диаметр, Å). По умолчанию `4.0`.
    - *Третье:* активны оба поля `a` и `C` (эмпирический коэффициент).

3.  **Нажмите «Рассчитать и построить».**
    - Программа рассчитает ионную силу электролита.
    - Построит график трёх теоретических кривых.
    - Отметит вертикальной линией и точкой текущую концентрацию.
    - Выведет численные значения в панели «Результаты».

4.  **(Опционально) Загрузите экспериментальные данные:**
    - `Файл → Загрузить эксперимент (.csv)`
    - Выберите файл в формате: `sqrt(I), lg(γ±)`.
    - Экспериментальные точки отобразятся на графике зелёными кружками.

5.  **Экспортируйте результаты:**
    - `Файл → Экспорт графика (PNG)` — сохраняет рисунок с высоким разрешением.
    - `Файл → Экспорт результатов (CSV)` — сохраняет таблицу `sqrt(I), I, lg1, lg2, lg3`.
    - `Файл → Экспорт отчета (PDF)` — генерирует документ с параметрами, результатами и графиком.

## Форматы файлов

### Входной CSV (экспериментальные данные)

```csv
sqrt(I),lg_gamma
0.1000,-0.0452
0.2000,-0.0801
0.3000,-0.1098
0.4000,-0.1354
0.5000,-0.1550
```

- Разделитель — запятая.
- Первая строка — заголовок.
- Первый столбец — `√I` (корень из ионной силы).
- Второй столбец — `lg(γ±)` (десятичный логарифм коэффициента активности).

### Выходной CSV (результаты)

```csv
sqrt(I),I,lg_gamma_1,lg_gamma_2,lg_gamma_3
0.0000,0.000000,0.000000,0.000000,0.000000
...
0.7000,0.490000,-0.356300,-0.287615,-0.238615
```

- Содержит 100 точек для построения гладких кривых.

## Архитектура программы

Программа построена по принципу **Model-View** (разделение логики и интерфейса).

| Компонент | Класс / Модуль | Назначение |
|:---|:---|:---|
| **Физическая модель** | `DebyeHuckelModel` | Реализует формулы трёх приближений и расчёт ионной силы. |
| **Графическое представление** | `MplCanvas` | Холст Matplotlib, встроенный в Qt. |
| **Главное окно** | `MainWindow` | Интерфейс пользователя, связь с моделью, обработка событий. |
| **PDF-экспорт** | Метод `save_pdf` | Генерация отчёта средствами `reportlab`. |

**Ключевые особенности реализации:**
- Все расчёты ведутся в логарифмической шкале (`lg γ±`) для избежания потери точности.
- Автоматическое определение стехиометрии электролита через НОД зарядов.
- Динамический диапазон оси X: программа подстраивает масштаб графика под введённую концентрацию.

### Пример 1: Демонстрация пределов применимости

- Электролит: NaCl (`z+=1`, `z-=-1`).
- Концентрация: `0.1` моль/л.
- Параметр `a`: `4.0` Å.
- Наблюдение: кривая 1-го приближения (пунктир) уходит значительно ниже экспериментальных данных, в то время как 2-е и 3-е приближения дают физически корректный результат.
